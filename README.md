# Kathy's Programmer Profile 🐱🎀

A responsive, cat-themed portfolio built with Next.js and CSS. The design uses pastel pink, soft yellow, cream, rounded cards, playful details, and a custom cat illustration.

## Sections

- Home
- About
- Education
- Projects
- Contact

## Run locally

Install Node.js, then run:

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Deploy

Import this repository into Vercel. Vercel will detect Next.js automatically.
